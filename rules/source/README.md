# 規則來源文件

明細檢核規則 (`src/rulesets/life.js`) 依下列主辦單位文件實作。檔案不放進版控，請自行放在這個資料夾：

| 檔名 | 用途 |
|---|---|
| `附件二_人壽保險業個人壽險填報手冊_2025填報年度.pdf` | 欄位格式、代碼表 |

| `新式癌症保險填報手冊_2024.pdf` | 延伸險種 (尚未實作) |
| `新式傷害保險填報手冊.docx` | 延伸險種 (尚未實作；主辦單位提供的是 Word 檔) |

規則匯入分頁可直接上傳這些檔案，由 AI 轉成可執行規則。
