此頁的規則優先於 `../MASTER.md`。

| 用途 | 淺色 | 深色 |
|---|---|---|
| 背景 | #FAFAF9 | #0C0A09 |
| 卡片 | #FFFFFF | #1C1917 |
| 文字 | #0C0A09 | #FAFAF9 |

| 主色（按鈕、粗線） | #1C1917 | #FAFAF9 |

## 字體

- 標題、大數字：Cormorant＋Noto Serif TC
- 內文：Montserrat＋Noto Sans TC
- 程式碼與原始資料：Fira Code

## 版面

- 單頁流程：放入資料 → 四個重點數字 → 找到的問題（表格＋右側說明）→ 動作按鈕。
- 進階功能（數字核對明細、看懂退件通知、新增檢查規則、預覽報告、檢查項目一覽）收在頁尾一行，進入後上方有「回到檢查結果」。
- 方角（2px 以下）、細線分隔、無陰影；小標題全形字距加寬。
- 在電腦上直接開啟時沒有 AI，AI 按鈕與提示不顯示。
