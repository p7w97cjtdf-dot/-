# 壽險填報檢核助手 · Data Quality & Validation Assistant

THEME 6 | Finance, Actuarial & Data Management — **6-2 資料品質與檢核助手**

壽險公司每年向保發中心申報「個人壽險」承保檔與給付檔，資料缺漏、格式錯誤或不符檢核規則就會被退回，需要花大量時間重新檢查與修正。本工具讓使用者上傳申報檔後，**依填報手冊的既定檢核規則逐欄、逐筆、跨檔自動驗證**，標示未通過的項目、給出修正建議（可一鍵套用的會直接算出正確值），並自動產生檢核結果報告；再由 **Claude** 歸納錯誤的根本原因、修正優先順序與退件風險。

## 快速開始

不需安裝，直接用瀏覽器開啟 `index.html`。頁面開啟時已載入一組含 38 項刻意錯誤的模擬資料。

```bash
# 命令列檢核 (Node 18+)：錯誤時 exit code = 1，可接在轉檔排程後
node tools/validate.js samples/dirty/LFL01_2025.txt samples/dirty/LFD01_2025.txt --html 檢核報告.html

npm test                 # 執行測試
npm run samples          # 重新產生 samples/ 模擬資料
```

## 功能

| 需求 | 做法 |
|---|---|
| 依據檢核規則自動驗證 | 256 條規則，檢核編號沿用手冊「(新)檢核編號」(例 `20200_L0612`)，可在「檢核規則」分頁查詢 |
| 找出缺漏與格式錯誤 | 檔名、每筆長度 (425/225)、空白行、全形字、數字欄前補 0、文數字靠左、不可空白/不可為 0 |
| 檢查資料邏輯是否合理 | 單筆邏輯 (日期先後、期間別與期間、商品類別編碼、分紅類別與起保年…)、多筆邏輯 (異動序號、加保別=上一筆退保別、停效→復效、保額增減方向…)、承保與給付跨檔對帳 |
| 標示未通過檢核項目 | 問題清單依嚴重度/檔案/類別篩選；點選後以「欄位尺規」標出該欄在原始資料中的字元起迄位置，並列出同保單其他異動 |
| 提供修正建議 | 每項都有建議；可推得正確值的 (如年滿期迄日、異動序號、補前置 0) 可單筆或一鍵套用並下載修正後檔案 |
| 自動產生檢核報告 | 獨立 HTML 報告、問題清單 CSV、保發中心風格的「不符資料檔」 |
| AI | Claude 產生分析摘要 (根因分群、修正優先順序、退件風險、預防建議) 與單一問題解釋 |

### 規則引擎與 AI 的分工

檢核本身由規則引擎執行：結果可重現、可稽核，每一項都對得回手冊條文。AI 不負責判定對錯，而是負責**解讀**：把幾十項錯誤歸納成「轉檔程式沒補前置 0」「民國/西元混用」「承保與給付系統未對帳」這類系統性原因，告訴使用者先修哪裡。送給 AI 的只有檢核摘要與問題清單，證件號碼不會送出。

AI 功能需要 Anthropic API key（在頁面輸入，只存在使用者自己的瀏覽器），使用 `claude-opus-5-5`。沒有 key 時其他功能都能正常使用。

## 檢核涵蓋範圍

依據 `附件二_人壽保險業個人壽險填報手冊_2025填報年度` 與 `新式個人壽險填報說明手冊範例&檢核規則_2025`：

- **承保資料檔** `LFLxx_yyyy.txt`：61 欄、每筆 425 字元
- **給付資料檔** `LFDxx_yyyy.txt`：31 欄、每筆 225 字元
- 代碼表：公司代號、加保別/退保別、保單分紅類別、保險商品類別編號、身心障礙、經濟弱勢、通路、幣別、郵遞區號前 3 碼…
- 以 `X` 開頭的檢核編號是本工具補充的「邏輯合理性」檢查 (臺幣保單原幣=臺幣金額、投保年齡、保額異常偏高…)，預設為警告

手冊中「(放寬不檢)」的條文未實作；少數文字有歧義的條文 (例如歲滿期迄日推算、累計繳費月數理論值) 以警告呈現，避免誤擋。

## 模擬資料與驗證

`src/mock.js` 依手冊格式產生模擬保單 (新契約、持續有效、停效復效、保額增加、繳清、解約、滿期、疾病/意外死亡、生存還本、外幣保單)，再注入 38 種錯誤並輸出解答 `samples/dirty/answer-key.json`。測試確認：

- 注入的 38 項錯誤全部偵測到，且不會誤報在未注入錯誤的保單上
- 正確資料在 5 組不同亂數種子下皆 0 錯誤 0 警告
- 手冊「範例一(新加保)」的欄位值通過所有檢核
- 套用自動修正後錯誤數下降

## 專案結構

```
index.html              網頁介面
src/core.js             固定長度解析、檢核執行、自動修正 (瀏覽器與 Node 共用)
src/rulesets/life.js    個人壽險欄位格式、代碼表、檢核規則
src/report.js           文字 / CSV / HTML 報告、不符資料檔
src/mock.js             模擬資料產生與錯誤注入
src/ai.js               Claude 分析摘要與問題解釋
tools/validate.js       命令列檢核
tests/                  node:test 測試
samples/                clean/ 正確範例、dirty/ 含錯誤範例 (含 CSV 版本)
```

## 延伸

規則集與引擎分離：其他險種 (個人傷害保險、癌症保險、個人年金) 的填報手冊格式相同，新增一個 `src/rulesets/*.js` 定義欄位、代碼表與規則即可沿用同一套介面、報告與 AI 分析。主辦單位提供正式檢核規則後，也只需調整規則集。
